### 3) Secrets and Credentials Handling

- Credential sources: environment variables (`NVIDIA_API_KEY` for NVIDIA profiles; `GH_TOKEN` for `gh` CLI); `NVIDIA_BASE_URL` (optional override for proxy upstream, default `https://integrate.api.nvidia.com`).
- Hardcoding checks: no hardcoded API keys or tokens found in source; `NVIDIA_API_KEY` is read from `os.environ` at proxy request time (`src/agent/nvidia_proxy.py` `proxy()` route).

### 4) Reliability and Failure Behavior

- Retry/backoff behavior: proxy retries up to `MAX_RETRIES = 5` on HTTP 429, honoring `Retry-After` header with linear backoff fallback (`5 * attempt` seconds) (`src/agent/nvidia_proxy.py`).
- Timeout policy: upstream request timeout `REQUEST_TIMEOUT_SECONDS = 600.0`; CLI proxy health check timeout 1.0 s; proxy start timeout `PROXY_START_TIMEOUT_SECONDS` (`src/agent/constants.py`, `cli.py`).
- Circuit-breaker or fallback behavior: none implemented; if NVIDIA is unreachable, requests fail after retries (`{"error": "Max retries exceeded"}` 429). Ollama has no retry/fallback in the CLI (`_run_with_ollama` just launches `opencode`).

### 5) Observability for Integrations

- Logging around external calls: proxy logs rate-limit warnings and 500 when `NVIDIA_API_KEY` is missing; CLI logs profile selection and proxy lifecycle (`logging.INFO`) (`src/agent/nvidia_proxy.py`, `cli.py`).
- Metrics/tracing coverage: none detected (no Prometheus, OpenTelemetry, or APM integration).
- Missing visibility gaps: no request latency/error metrics; no dashboard; no tracing across compose/apply pipeline stages.
